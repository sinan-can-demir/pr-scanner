# Security Policy

This tool is itself security-sensitive. Please report vulnerabilities privately.

- **Report:** open a private security advisory on the repository (preferred), or email the maintainer. Do not file public issues for vulnerabilities.
- **Scope:** evasion that defeats a documented rule, prompt injection, token exposure, execution of PR content, supply-chain issues in this repo's dependencies or workflows.
- **Response:** acknowledgement within 3 business days; status updates at least weekly.
- **Safe harbour:** good-faith research is welcome; do not test against repositories you do not own.

Known limitations are listed in `docs/04-threat-model.md` (residual risk column).
