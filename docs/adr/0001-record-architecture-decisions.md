# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-02

## Context
Design decisions in a security tool must be traceable and revisitable.

## Decision
Use lightweight ADRs in `docs/adr/`, numbered sequentially, with Status / Context / Decision / Consequences. Superseded ADRs are kept and marked.

## Consequences
Small overhead per decision; much better onboarding and audit trail.
